# 🔒 Securechat

A secure messaging platform designed to provide private, encrypted, and real-time communication.

✨ Key Features

End-to-End Encryption: Ensures that only participants in conversations can read the exchanged messages.

Role and Permission Management: A comprehensive system (Owner, Admin, Tester, Friend, Member) to secure access to administrative and moderation features.

Dynamic & Custom Themes: Support for seasonal themes (Halloween, Christmas, Valentine's Day, Summer, etc.) and temporary overrides managed directly via the database.

Interactive Features: Image sharing, message reactions, voting system, and real-time typing indicators.

Enhanced Security: Strict Firebase Security Rules to prevent unauthorized access to sensitive data.
