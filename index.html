Déployer sur GitHub Pages

  1. Créez un dépôt public sur GitHub nommé mon-chat-securise.
  2. Créez un fichier nommé exactement index.html.
  3. Collez l'intégralité du code de cette page dans ce fichier et enregistrez (Commit).
  4. Dans les paramètres du dépôt (Settings > Pages), choisissez la branche main / root et sauvegardez.
